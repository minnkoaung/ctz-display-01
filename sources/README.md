# Source fonts

These are the exact OFL-licensed binaries used by the CTZ Display 01 build:

- Inter 4.001 upright variable (`opsz`, `wght`)
- Inter 4.001 italic variable (`opsz`, `wght`)
- Pyidaungsu 2.5.3 Regular
- Pyidaungsu 2.5.3 Bold
- Pyidaungsu 2.5.3 Numbers, retained for reference but not merged

The combined font uses Inter for ASCII digits and Pyidaungsu for Myanmar digits U+1040–U+1049. See the repository OFL license and attribution notices before redistribution.
